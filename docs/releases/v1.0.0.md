# Medo 1.0.0 — Stable Windows

Primera versión estable de Medo para Windows.

## Qué es Medo

Medo es una aplicación de escritorio para escribir, previsualizar, guardar y exportar documentos Markdown de forma local, sobria y confiable.

## Funcionalidades principales

- Editor Markdown.
- Vista previa en vivo.
- Nuevo, Abrir, Guardar y Guardar como.
- Recuperación de borrador local.
- Exportar HTML limpio.
- Imprimir / Guardar como PDF.
- Preferencias locales persistentes.
- Tema claro / oscuro / sistema.
- Tamaño de fuente del editor.
- Manual de uso integrado.
- Acerca y Novedades.
- Links internos con anchors.
- Tabla de contenidos automática.
- Soporte práctico para archivos Markdown dentro de WSL mediante rutas UNC.
- Instalador Windows NSIS con icono de Medo.

## Instalación

1. Descargar `Medo_1.0.0_x64-setup.exe`.
2. Ejecutar el instalador.
3. Abrir Medo desde el menú Inicio o acceso directo.

## Aviso de SmartScreen

Medo todavía no está firmado digitalmente con certificado de editor. Windows puede mostrar “Editor desconocido”. Si descargaste el instalador desde el release oficial, seleccioná “Más información” y luego “Ejecutar de todas formas”.

La firma digital será evaluada para versiones futuras.

## Verificación

SHA256 del instalador:

`PENDIENTE_DE_COMPLETAR_AL_PUBLICAR_RELEASE`

El release puede incluir un enlace de análisis de VirusTotal como referencia. VirusTotal no certifica la app; solo muestra resultados de múltiples motores antivirus. Si aparecen falsos positivos, se pueden reportar a los vendors correspondientes.

## Plataforma soportada

- Windows: soporte estable inicial.
- WSL: uso práctico mediante rutas UNC de Windows.
- Linux/macOS: no incluidos en esta release.
